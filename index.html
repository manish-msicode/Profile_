Agentic AI · Production Systems · 2026

DispatchDesk — AI Customer Support Agent — GitHub 2026

Python · LangGraph · FastAPI · Redis · Chroma · Pydantic · SQLite · JWT · bcrypt · Docker

  • Built a LangGraph + FastAPI support system that dynamically routes user queries across 4 tools (order lookup, RAG Q&A, refund initiation, escalation) based on intent classification.
  • Reduced ungrounded policy answers by grounding responses in a 10-document policy corpus via Chroma vector search, validated across a 30-case test suite.
  • Engineered a Redis-backed semantic cache that cut p95 policy-lookup latency from ∼600ms to ∼80ms on cache hits (cache misses re-populate the cache for subsequent calls), by serving cached responses before triggering OpenAI embedding + Chroma vector search.
  • Reduced LLM cost per query by ∼20–27% (from ∼$0.00075 to ∼$0.00055 per query at GPT-4o-mini rates, based on 1K simulated queries) by reusing cached context to skip redundant embedding and completion calls on repeated policy-intent queries.
  • Secured the API (FastAPI, JWT, bcrypt, RBAC) by replacing plaintext auth with OAuth2 JWT + role-based access, locking refund-approval endpoints to supervisor-only roles.
  • Moved refund-approval business rules out of the LLM prompt into deterministic, transactional code (SQLite, ACID), enforcing idempotency and eliminating duplicate refunds — verified with a 6-case pytest suite.
  • Containerized the full stack with Docker and Pydantic-validated schemas across 5 REST endpoints, enabling one-command local deployment with environment-based secrets.
